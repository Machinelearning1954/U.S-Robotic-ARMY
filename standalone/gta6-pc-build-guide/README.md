## Key takeaways

- **GPU is the ceiling** — 16 GB+ VRAM for 4K ultra + ray tracing.
- **Multi-core CPU** prevents simulation-bound stutter in dense scenes.
- **NVMe SSD is non-negotiable** for streaming; budget 150 GB for the install.
- **Future-proofing** = RTX 50 series / RX 9000 with 16 GB+ VRAM.
