What this is

A forge for structured scene-generation prompts aimed at Claude Fable 5. You dial in a scene, weather, lighting model, camera, Leonida region, detail tier, and target device — it assembles a precise, multi-section prompt you can paste into a chat to have Fable 5 write a GTA-6-tier scene description, shot list, or render brief.

Honest scope: this generates prompts and scene descriptions. It does not itself render 3D graphics or run a game engine — no app on a phone renders true GTA 6 at native 4K. For real in-browser ray tracing, see the WebGPU path tracer in this repo (game/city_rtx.html).

Device targets

The prompt bakes in the right GPU/API hints per device:

• Lenovo Legion 7i — RTX laptop GPU, DX12/Vulkan, hardware ray tracing + DLSS.
• iPhone 16 Pro — A18 Pro, Metal 3, MetalFX upscaling.
• Galaxy Fold 6 — Snapdragon 8 Gen 3, Vulkan, foldable dual-screen layout.

How to use

1. Forge a prompt. 2. Copy it. 3. Paste it to Claude Fable 5. 4. Save the ones that work. Everything saves locally in your browser — nothing leaves the device.
