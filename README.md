# Cloud Runner — GTA 6 Free Cloud Gaming Edition

A self-contained browser arcade game that integrates the **Free Cloud Gaming
Solutions for GTA 6 (July 2026)** guide directly into gameplay.

## Play

Open `index.html` in any modern browser — no build step, no server, no
external assets. All graphics are rendered locally on a `<canvas>`.

## How the guide is integrated

- **Pickups** — the four cloud services from the guide (GeForce NOW free tier,
  Xbox Cloud Gaming, Amazon Luna, Remote Play) fall from the sky as cloud
  tokens. Collecting one for the first time shows its real facts from the
  guide (cost, session limits, GTA 6 availability estimate).
- **Hazards** — the guide's "cons" appear as obstacles: *Paywall*, *Queue*,
  and *1-hour session cap*. Hitting one costs points and session time.
- **Session timer** — the run lasts 60 seconds, an arcade-scaled nod to the
  GeForce NOW free tier's 1-hour session limit.
- **In-game guide screen** — the full guide (overview, all four services, the
  comparison table, key takeaways, and references) is readable from the main
  menu or the game-over screen via the **Cloud Gaming Guide** button.
- **Win condition** — collect all 4 services before the session expires; the
  ending echoes the guide's key takeaway ($1 Game Pass Ultimate trials around
  November 2026 are your best bet).

## Controls

| Input | Action |
|---|---|
| Arrow keys / WASD | Move |
| P | Pause / resume |
| Touch drag | Move (mobile) |

## Guide snapshot (July 2026)

GTA 6 is scheduled for November 19, 2026 on PS5 and Xbox Series X|S. There is
no truly free launch-day cloud option; the full comparison lives in the
in-game guide screen.
