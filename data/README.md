# Data

This directory holds the datasets used for military vehicle recognition.

## Layout

```
data/
├── raw/         # Original, immutable downloads (git-ignored)
├── interim/     # Intermediate, partially processed data (git-ignored)
└── processed/   # Final, model-ready datasets (git-ignored)
```

Large data files are **not** committed to git — see the project `.gitignore`.
Track them with [Git LFS](https://git-lfs.com/) or [DVC](https://dvc.org/)
instead, and document each source (name, URL, license) here.
