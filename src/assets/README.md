# Assets

## Custom intro video

Drop a file named `intro.mp4` in this folder and REZONANCE will play it as the
opening cutscene when you hit **BEGIN SWEEP** (click or press any key to skip).

If no `intro.mp4` is present, the game falls back to its built-in animated
briefing (rain over the Halcyon Bay skyline, scanner waveform, handler
message).

Only use footage you own the rights to.

## Title key art

The title screen looks for `keyart.png` in this folder first, then falls back
to the hosted original (generated with Higgsfield for this project):

https://d8j0ntlcm91z4.cloudfront.net/user_3DecqKTontO540o5h6oTceJuUaD/hf_20260718_185334_4f64cefc-3ecc-4ae9-bf53-3f46a5873b2c.png

To pin it locally (recommended — survives the hosted copy ever vanishing),
download that URL and save it here as `keyart.png`. If neither is available
the CSS-only title screen still works.
